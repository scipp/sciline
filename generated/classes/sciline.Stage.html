sciline.Stage#

class sciline.Stage(pipeline, *, outputs, inputs, scheduler=None)[source]#

The part of a pipeline from a set of input keys to a set of output keys.

Everything the outputs need that does not depend on the inputs is computed once, on first use or by prepare_stages(). Of this part, the stage caches the values that the per-call part reads, and the outputs that do not depend on the inputs. Each call to run() supplies values for the inputs and computes only what lies downstream of them. An input may be a parameter or an intermediate result; in both cases its own provider and ancestors are cut off. An output that is also an input is passed through. Keys given as inputs that the outputs do not need, for example because another input cuts them off, are dropped; inputs lists the rest.

A stage is a snapshot of the pipeline at the time it is built. Later changes to the pipeline do not affect it. Parameter values are kept by reference, not copied, so modifying a value in place can change what the stage computes.

run() may be called from several threads at once. Even then, the part that does not depend on the inputs is computed only once.

Parameters:

  • pipeline (Pipeline) – Pipeline with all parameters set that the outputs need, except the inputs.

  • outputs (Iterable[type]) – Keys whose values the stage computes.

  • inputs (Iterable[type]) – Keys at which the pipeline is cut, supplied on each call. Those the outputs do not need are dropped.

  • scheduler (Scheduler | None, default: None) – Scheduler for computing the cached values and the per-call part. If not given, sciline.scheduler.DaskScheduler is used if dask is installed, otherwise sciline.scheduler.NaiveScheduler.

Raises:

ValueError – If the pipeline has neither a provider nor a value for an output that is not an input.
